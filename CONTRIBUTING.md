# Contributing to MoonAi

Thanks for your interest in contributing to MoonAi!

---

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/Sorogaia/moonai.git`
3. Open `moonai.html` in your browser to run locally
4. Make your changes
5. Submit a pull request

## Development

MoonAi is a single HTML file — no build tools, no dependencies, no npm install needed. Just open the file in a browser.

To run with live reload:
```bash
npx live-server .
```

## What We're Looking For

- Bug fixes
- UI/UX improvements
- New trading platform integrations
- Performance improvements
- Accessibility improvements

## What to Avoid

- Do not hardcode API keys
- Do not add external dependencies without discussion
- Keep the single-file architecture for V1

## Reporting Bugs

Open a GitHub Issue with:
- What you did
- What you expected
- What actually happened
- Browser and OS
