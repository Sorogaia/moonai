# Setup Guide

## Using MoonAi

No API key needed. No signup. No install.

1. Go to [moonaiapp.xyz](https://moonaiapp.xyz)
2. Paste any Solana CA or pump.fun link
3. Done

---

## Running Locally

```bash
git clone https://github.com/itsyaboihomelander/moonai.git
cd moonai
npx live-server .
```

> AI chat and on-chain data require the backend to be running.

---
